## Single-PRC installation

Version 0.8 adds an installer that applies both WPA2 patches and installs the **E2 WPA2 Test** status app. The same app can restore the stock driver and Wi-Fi Setup panel.

Download [E2WPA2Patcher.prc](https://github.com/palmsnipe/palm-wifi-sdio/releases/download/v0.8/E2WPA2Patcher.prc) and transfer it directly to a Tungsten E2 with the original palmOne v1.2 Wi-Fi software installed. The app appears as **E2 WPA2 Installer**. CloudpilotEmu verified install, WPA2 and protected DHCP after reset, and stock restore. All patched Wi-Fi resources matched the candidate tested on physical hardware.

The ZIP also supports generating a combined installer. Extract it and run the patcher with Python 3 and your original palmOne v1.2 installer.

```sh
python3 apply.py --single /path/to/WiFi_Installer1.2.prc palm-wpa2-prcs
```

Transfer the generated `E2WPA2Installer.prc` to internal memory. Keep the combined PRC private because it includes resources from your local palmOne software. [Installation and rollback guide](https://github.com/palmsnipe/palm-wifi-sdio/blob/main/doc/palmone-e2-wpa2.md#install-from-a-single-prc)

## Verified on a physical Tungsten E2

- **WPA2 connection** reached **Stage 22 / Detail 0000**.
- **IP configuration** showed an assigned address in Wi-Fi Info.
- **Restore Stock** worked after reset.

The tests used the installer generated from the candidate ZIP attached to the Actions run below. The published ZIP is the tested build, so its bundled guide reflects the emulator results available at build time.
